# Natty-or-Not
Guia visual de triagem no Windows 11, criado para o desafio Natural ou Fake Natty? da DIO. Um chamado simulado acompanha um estudante cujo notebook fica lento ao assistir a uma videoaula e manter vários aplicativos abertos. O guia mostra como investigar a lentidão e comparar o comportamento antes e depois de uma mudança reversível.
