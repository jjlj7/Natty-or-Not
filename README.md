# Computador lento?

## Descrição

Guia visual de triagem no Windows 11, criado para o desafio Natural ou Fake Natty? da DIO. Um chamado simulado acompanha uma estudante cujo notebook fica lento ao assistir a uma videoaula e manter vários aplicativos abertos. O guia mostra como investigar a lentidão e comparar o comportamento antes e depois de uma mudança reversível.

![Notebook aberto em uma mesa de estudos. Ilustração gerada por IA.](mesa-de-estudo.png)

## Tecnologias utilizadas

- ChatGPT para estruturar o roteiro e redigir o caso didático.
- ImageGen integrado ao Codex para gerar as duas ilustrações.
- Python e ReportLab para diagramar o PDF.
- Markdown para documentar o projeto.

## Processo de criação

1. Defini o cenário de uma videoaula e as perguntas iniciais do chamado.
2. Usei a documentação da Microsoft como referência para as etapas de triagem.
3. Criei duas imagens fotorrealistas com IA e identifiquei sua origem no guia.
4. Organizei o PDF com roteiro, pistas e um exemplo de reteste.

### Prompts das imagens

- **Mesa de estudo.** Fotografia documental fotorrealista, horizontal 3:2 para capa de guia de suporte técnico. Notebook cinza aberto em mesa de estudo doméstica brasileira, com caderno, luz lateral suave e tela desfocada com navegador aberto. Texturas naturais, sombras reais, cenas cotidianas, enquadramento em três quartos. Sem texto legível, marcas, logotipos ou marcas d’água.
- **Triagem do notebook.** Fotografia documental fotorrealista, horizontal 3:2 para guia de suporte técnico. Vista por cima do ombro de uma pessoa em mesa de estudo doméstica, mãos em posição natural no teclado de notebook cinza, janela genérica de gráficos de desempenho bem desfocada, caderno ao lado, luz natural suave. Sem texto legível, marcas, logotipos, números legíveis ou marcas d’água.

## Reflexão

As imagens parecem fotografias de um atendimento cotidiano. Os rótulos de origem e os valores marcados como simulados ajudam o leitor a distinguir a ilustração das evidências que precisaria coletar em um atendimento real.
